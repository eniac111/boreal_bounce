# Credits

Boreal Bounce is a fork of **Frozen-Bubble** (https://www.frozen-bubble.org/), Copyright
2000-2012 The Frozen-Bubble Team, released under the GNU General Public License version 2.
The game engine was rewritten from scratch on Godot 4; all artwork, music, sound effects,
levels and translations are reused from the original game and remain the work of the people
listed below. The name "Frozen-Bubble" and its logo are not used by this fork.

Boreal Bounce is distributed under the same license (see `COPYING`).

## Boreal Bounce

- Blagovest Petrov, current developer of the fork: the Godot 4 rewrite, the asset pipeline
  and the new text-based interface. https://petrovs.info, blagovest@petrovs.info

## Fonts

- Playpen Sans (display font for Latin, Cyrillic and Greek), Mochiy Pop One (Japanese),
  ZCOOL KuaiLe (Chinese), Lalezar (Persian/Arabic), Baloo 2 (Devanagari): SIL Open Font
  License 1.1, see `assets/fonts/display/OFL-*.txt`.
- DejaVu Sans (runtime text): Bitstream Vera licence, see `assets/fonts/LICENSE-DejaVu.txt`.

## Build tools

- Real-ESRGAN (https://github.com/xinntao/Real-ESRGAN, BSD 3-Clause) is used at asset-import
  time to upscale the original sprites for high-resolution displays; it is not part of the
  shipped game.
